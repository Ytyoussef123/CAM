Add the photos to check. Click one to see its result, or press Run line to inspect them in sequence like a production line.

Sample loaded: machined flanges generated in the browser. 10 good parts teach the model; the inspection set mixes good parts with a missing bolt hole, a scratch, an edge chip and a stain. You can drag your own photos onto steps 1 and 3.

With the phone camera: press Start camera, fix the phone (stand or tape) above the part, clear the samples, capture 5–20 good parts, press Learn OK, then press Trigger once (or Run line for one capture every 2.5 s) for each part to check. The faint ghost shows the learned part so you can place the next one in the same spot.

How this version works: it compares each pixel to the average of the good parts, so parts must sit in the same position, as on a fixture. The Python version with PatchCore will tolerate more movement.
