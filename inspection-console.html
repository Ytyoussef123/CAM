Control areas on the sensor

Changing a threshold here changes it on the phone.

1

Reference image

—

Put one good part in its exact position and take the reference picture. Everything else is set on this image.

2

Control areas

—

Press + Draw area, then drag a box on the image around what must be checked (a hole, a label, an edge…). Only these areas are inspected. Drag inside a box to move it.

3

More good parts

—

Recommended: add 5–20 more photos of good parts (take each part out and put it back). The sensor learns normal variation and sets the thresholds by itself.

4

Inspect parts

—

Put a part in place and take a picture: the result appears at once (and on the PC). With the live camera, Run line takes one picture every 2.5 s.

How it works: each picture is compared pixel by pixel with the reference and the good parts, inside the control areas only. An area whose score is above its threshold is NG, and one NG area makes the part NG. Parts must sit in the same place each time, as on a fixture: the faint reference ghost on the live image helps you place them.
